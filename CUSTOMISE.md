# Customise your website

Visit https://bennygaming635.github.io/ and click **Customise this site** in the footer.

1. Edit your name, introduction, interests, projects, tools, and social links.
2. Click **Save preview** to see changes. These are stored only in your current browser; visitors still see the published version.
3. Click **Download index.html** to save your updated website.
4. Open https://github.com/BennyGaming635/bennygaming635.github.io, choose **Add file → Upload files**, upload the downloaded file as `index.html`, and commit to `main`.
5. GitHub Pages publishes the change automatically. Allow a minute or two, then refresh.

Each project uses `Title | Description | URL`. Each social link uses `Name | URL`. Put one entry on each line. Leave a project's URL blank to display it without a link. Use full `https://` URLs or `mailto:` addresses.

**Reset preview** restores the currently published content. The editor is a local preview tool, so visitors cannot change the public website through it. Publishing requires access to your GitHub repository.

The site is a single HTML file with no build step, dependencies, trackers, or external fonts. Its two project illustrations are original inline SVG drawings. Existing pages under `ninja/` are retained.
